# Got Got Need

Swap Topps Flagship Premier League 2026/27 cards with friends. Add your swaps and the cards you've got, and the app shows who to swap with and sends swap offers.

**Live:** https://elkerton-13.github.io/got-got-need/

- `docs/` is the app, served by GitHub Pages (Settings > Pages > Deploy from a branch > `main` / `docs`).
- `docs/config.js` holds the Firebase web settings (not secret).
- `firestore.rules` holds the database security rules. Paste them into Firebase console > Firestore Database > Rules whenever they change.
- `SETUP.md` covers setting the app up from scratch.
